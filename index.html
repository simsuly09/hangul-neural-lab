ABOUT THIS PROJECT

한글 신경망 실험실

손글씨를 입력하면 이미 학습된 인공신경망이 수행하는 추론을 3D로 보여주는 교육용 프로그램입니다. 그림을 쓸 때마다 새로 학습하지 않습니다.

AI Hub 제공 모델을 브라우저용 형식으로 변환하여 함께 제공합니다. 사이트에 접속하면 자동으로 불러옵니다. 원본 학습·검증 데이터는 포함하지 않습니다. 선택한 파일과 그린 이미지는 서버로 전송하지 않습니다. 기억하기를 선택하면 모델은 현재 브라우저의 저장 공간에 보관됩니다.

이 프로젝트는 한국지능정보사회진흥원 AI Hub 사업 결과인 ‘다양한 형태의 한글 문자 OCR’을 활용합니다. 해당 모델은 독립된 세 CNN으로 초성 19개, 중성 21개, 종성 28개를 각각 예측합니다. 분기마다 합성곱 12층, 최대 풀링 4층, Flatten, 출력층이 있습니다.

추론은 모든 층과 채널을 사용합니다. 3D 개요에서는 주요 층의 최대 4개 채널과 일정 간격의 공간 위치를 표시하며, 밝기는 층별 최댓값으로 조절합니다. 실제 수치는 상자 위에 마우스를 올리거나 연산 패널에서 확인할 수 있습니다.

기본 예시는 코드로 직접 그린 도형입니다. 예시 결과로 전체 검증 정확도를 판단할 수 없습니다. 인식 오류를 포함해 실제 모델 출력을 그대로 표시합니다.

시각화 참고: okdalto/conv_visualizer. 화면과 계산 연결 코드는 별도로 구현했습니다.
